# Mission Framework — vendored operational procedure

TimeLapse Pro is a named reference mission in [`froekjaer/mission-framework`](https://github.com/froekjaer/mission-framework) (Apache-2.0) — see that repo's `README.md` and `MISSION.md` for the framework's continuity and independent-verification proposition, which this project is expected to test in practice.

`OP-001-Mission-Operational-Preamble.md` in this folder is a verbatim, vendored copy of the framework's canonical pre-work procedure, kept in this repo rather than only referenced externally — per the framework's own continuity principle, mission-critical procedure should not depend on a single external source being reachable.

The five AI collaborators active on this repo (Claude, Codex, ChatGPT, Kimi, Gemini) each have a short, tool-specific loader at the repo root (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`) or in `Dokumentation/` (`CHATGPT-PROJECT-INSTRUCTIONS.md`, since ChatGPT has no auto-loading convention) pointing back to this file plus this repo's own authoritative sources (`HANDOVER_LOG.md`, the GRC register, the architecture ratchet).

If this vendored copy and the upstream repo ever diverge, that divergence is itself worth recording as a Framework Finding (`docs/FRAMEWORK_FINDINGS.md` upstream) rather than silently resolved one way.
